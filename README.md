# SSH Jain PU College Website

Official website source for Sha Sheshaji Hasthimal Jain Arts, Commerce and Science Pre-University College, Harapanahalli.

The site is a responsive, accessible multi-page static website published with GitHub Pages.

## Structure

- `index.html` — admissions-led homepage
- `about.html` — story, vision, mission and institutional impact
- `academics.html` — Science, Commerce and Arts programmes
- `facilities.html` — A.D.B. Campus, laboratories and student facilities
- `leadership.html` — Chairman and Principal messages
- `faculty.html` — filterable staff directory
- `achievements.html` — results, toppers and alumni outcomes
- `admissions.html` — fees, process and Google Sheets-ready enquiry form
- `contact.html` — campus address, timings and common questions
- `assets/css` — shared design system
- `assets/js` — shared behaviour and faculty data
- `assets/images` — campus, people, laboratory and career imagery

Open `index.html` locally or publish the repository with GitHub Pages.
